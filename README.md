# benedek.fun

The website at https://benedek.fun, served for free by GitHub Pages from this repo's `main` branch.

| File | Address |
| --- | --- |
| `shutter/privacy-policy.html` | https://benedek.fun/shutter/privacy-policy |
| `index.html` | https://benedek.fun |
| `404.html` | any address that doesn't exist |

To change a page, edit the HTML, commit and push. The live site updates about a minute later.

The domain's DNS lives at GoDaddy: four `A` records for `@` pointing at GitHub
(185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) and a `www`
`CNAME` pointing at `gbls-bndk.github.io`. The `CNAME` file in this repo tells
GitHub which domain the site answers to.
